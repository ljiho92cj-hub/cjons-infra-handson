# AI Ops 프롬프트 템플릿

## 1. 알람 분류
역할: 인프라 장애 감시 및 보고자
입력: 아래 합성 alerts와 logs
지시:
- 시간순서로 정리
- 원인 가설을 최대 3개 제시
- 각 가설마다 원문 근거를 인용
- 근거가 부족하면 불확실하다고 표시
- 추가 확인 명령/지표를 제시
금지:
- 입력에 없는 사실 단정
- 실제 시스템 변경 명령 실행 지시
출력: 영향, 타임라인, 가설/근거, 추가확인, 우선조치 표

## 2. Runbook 초안
위 분석을 바탕으로 탐지→확인→완화→복구→검증→에스컬레이션 순서의 Runbook 초안을 작성하라.
각 단계에 승인 필요 여부와 롤백 방법을 표시하라.

## 3. Incident Report
영향, 탐지, 타임라인, 원인(확정/가설 구분), 조치, 검증, 재발방지, 미해결 위험을 포함하라.
