# HA 설계 캔버스

`scenario_cards.md`의 카드 하나를 골라 아래 10개 질문을 채우세요. 각 항목은 강의 세그먼트 1의 HA 5단계(감지·중재·격리·전환·롤백) 및 세그먼트 3의 롤백 3요소(트리거·수단·소요시간)와 대응합니다.

| 캔버스 항목 | 대응하는 HA 단계 | 채울 때 물어야 할 질문 |
|---|---|---|
| 서비스와 장애 경계 | (전체) | 어디까지가 정상, 어디부터가 장애인가? |
| 감지 지표/임계값 | 감지 | 무엇을 보고 이상을 판단하는가? 임계값은 얼마인가? |
| Quorum/Witness/Fencing | 중재·격리 | 몇 대 중 몇 대가 살아있어야 판단이 유효한가? 옛 주인을 어떻게 확실히 차단하는가? |
| Failover 시작 조건 | 전환 | 감지·중재를 통과한 뒤 전환을 실제로 시작하는 조건은? |
| 데이터 정합성 확인 | 전환 | 전환 후 데이터가 갈라지지 않았음을 어떻게 확인하는가? |
| 서비스 검증 | 전환 → 롤백(수단) | 전환이 성공했다고 판단하는 기준은? |
| **Rollback 조건** | **롤백(트리거)** | 무엇을 보고 되돌릴지 판단하는가? |
| RTO/RPO/SLO 영향 | 롤백(소요시간) | 전환·롤백에 걸리는 시간과 그동안의 서비스 영향은? |
| 커뮤니케이션 대상/메시지 | (운영) | 누구에게 언제 무엇을 알리는가? |
| 재발방지 | (운영) | 같은 장애가 재발하지 않으려면 무엇을 바꿔야 하는가? |
